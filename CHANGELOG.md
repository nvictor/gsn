# GUS Changelog

All notable changes to the Groove Unified Syntax (GUS) specification will be documented in this file.

## [1.0.0] - 2026-02-16

### Added
- Initial formalized specification.
- Definition of Core Axes: Pulse (P), Anchor (A), Syncopation (S), and Cadence (C).
- Basic symbol set for each axis.
- Interpretation rules and design principles.
